# La Peregrina · sitio web

Sitio institucional de La Peregrina (laperegrina.ar). Es un sitio estático: `index.html` contiene las cinco páginas (Inicio, Clásica 1994, 70% fruta, Gastronomía y Nosotros) y la carpeta `img/` las imágenes.

## Publicación en Render

Tipo de servicio: **Static Site**. Sin comando de build. Directorio a publicar: `.` (la raíz del repositorio).
